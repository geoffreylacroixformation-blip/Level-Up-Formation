\# LEVEL UP

\# Architecture fonctionnelle et technique

Version : 2.0

Statut : Document de référence

\---

\# Vision

Level Up est une plateforme de formation professionnelle spécialisée dans :

\- Systèmes  
\- Réseaux  
\- Cybersécurité  
\- Intelligence Artificielle

L'objectif est de proposer des formations modernes, pratiques et progressives.

\---

\# Philosophie

Chaque formation doit permettre à un élève de :

\- Comprendre  
\- Pratiquer  
\- Expérimenter  
\- Être autonome

L'accent est mis sur la pratique plutôt que sur la théorie.

\---

\# Les niveaux

Tous les cours appartiennent à l'un des trois niveaux suivants.

\#\# Level 1

Découverte.

Le cours permet d'apprendre les bases.

\---

\#\# Level 2

Approfondissement.

Le cours permet de devenir autonome.

\---

\#\# Level 3

Expert.

Le cours permet de maîtriser complètement une technologie.

\---

\# Les catégories

Chaque cours appartient à une catégorie.

Les catégories actuelles sont :

\- Systèmes  
\- Réseaux  
\- Cybersécurité  
\- Intelligence Artificielle

L'architecture permettra d'en ajouter d'autres sans modification importante.

\---

\# Fonctionnalités du MVP

Le MVP comprend :

\- Catalogue des cours  
\- Recherche  
\- Comptes utilisateurs  
\- Authentification Supabase  
\- Paiement Stripe  
\- Tableau de bord étudiant  
\- Suivi de progression  
\- Administration complète  
\- CRUD des cours  
\- CRUD des modules  
\- Gestion des offres commerciales

\---

\# Contenu des cours

Un cours est composé de plusieurs modules.

Chaque module peut contenir :

\- Markdown  
\- PDF  
\- Google Docs  
\- Google Slides  
\- Images  
\- Scripts Bash  
\- Scripts PowerShell  
\- Scripts Python  
\- Archives ZIP

Les contenus seront principalement affichés directement sur le site.

Les téléchargements resteront possibles uniquement lorsqu'ils présentent un intérêt pédagogique.

\---

\# Administration

L'administration permet :

\- Ajouter un cours  
\- Modifier un cours  
\- Supprimer un cours  
\- Publier un cours  
\- Dépublier un cours  
\- Ajouter des modules  
\- Ajouter des ressources  
\- Modifier les prix  
\- Gérer les promotions
